# 🎉 Convite Chá de Fralda

Este projeto é uma aplicação de página única (Single Page Website) desenvolvida para divulgar o Chá de Fralda de forma moderna, interativa e acessível para familiares e amigos.

## 🛠 Tecnologias

* HTML5 para estruturação.
* CSS3 para estilização, animações e responsividade.
* JavaScript puro para interatividade.
* Google Maps para localização do evento.
* WhatsApp API para envio de mensagens.

## 📑 Funcionalidades (Passo a Passo)

### 1. Navegação por Âncoras

**Lógica:** O menu utiliza links com o símbolo `#` que apontam para os IDs das seções da página.

**Funcionamento:** Ao clicar em uma opção do menu, o navegador navega automaticamente até a seção correspondente sem recarregar a página.

### 2. Controle de Música

**Lógica:** Uma função JavaScript monitora o clique no botão de música.

**Funcionamento:** O visitante pode iniciar ou pausar a música de fundo durante a navegação.

### 3. Localização do Evento

**Lógica:** Integração com Google Maps através de iframe.

**Funcionamento:** Permite visualizar o endereço do evento e acessar a rota diretamente pelo Google Maps.

### 4. Envio de Mensagens

**Lógica:** Um formulário captura o nome e a mensagem do visitante.

**Funcionamento:** Ao enviar, a mensagem é redirecionada automaticamente para o WhatsApp dos organizadores.

### 5. Lista de Mimos

**Lógica:** Exibição organizada dos itens sugeridos para presentear o bebê.

**Funcionamento:** Facilita a visualização dos produtos recomendados aos convidados.

### 6. Alteração de Tema

**Lógica:** Um botão permite alternar o visual da página.

**Funcionamento:** O usuário pode personalizar a experiência de navegação.
